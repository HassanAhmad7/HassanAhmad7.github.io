Dynamic Media Playback
in Camera Shots

Real-time media playback on dynamic materials for virtual-production camera shots, built entirely in Blueprints.

System overview

The system automates dynamic video playback on in-world screens, props, and backdrops at runtime. It creates the playback stack when needed and synchronizes the result with live virtual cameras.

What the system does

  • Creates a Dynamic Material Instance on a sprite or mesh screen.
  • Constructs the Media Player and Media Texture entirely in Blueprints.
  • Binds the video texture to the dynamic material.
  • Loads video from a runtime file path without requiring preloaded assets.
  • Plays media in sync with virtual cameras for cinematic shots.
01

Virtual production

Control the content shown on LED walls or digital signage from the active camera angle or scene logic.

02

Reusable setup

One modular Blueprint can be duplicated across multiple screens without rebuilding the playback logic.

03

Fast content changes

Change the video file path before a shot to display new content instantly—without reimporting media or editing materials.

Use cases

Cinematic cutscenes · In-camera VFX and previs · Virtual concert stages · Storyboard-driven content displays · Real-time visualizers

Avaturn Integration
& Motion Matching

A complete character pipeline covering avatar integration, custom IK, animation retargeting, motion-matched state selection, and geometry-aware traversal.

Character pipeline

I integrated a realistic Avaturn character into the project and built the supporting animation systems required to make it production-ready inside Unreal Engine 5.

Rigging and retargeting

  • Custom Avaturn animation IK Rig and Avaturn-to-UEFN IK Retargeter.
  • IK Goals and Full Body IK solver setup.
  • Manual rotation and root-bone adjustments.
  • An updated version of the Sandbox Character Animation Blueprint adapted for the Avaturn character.
01

Motion-matched states

Shooting, dancing, idle, walk, run, sprint, dash, super jump, and additional locomotion or action states.

02

Chooser tables

Animation selection and state switching for locomotion, armed movement, and idle variations.

03

AI movement

Move-to-location behavior bound to a double-click action on the map.

Improved traversal

The traversal system does not require tagged blocks or custom traversable actors. It traces the obstacle ahead, calculates its height and distance, and selects the appropriate traversal behavior.

CinematicAI
Agentic Director

An Unreal Engine editor plugin that translates creative intent and live scene context into structured, editable cinematography.

System overview

CinematicAI connects an agentic director workflow to Unreal Engine. A director supplies a prompt and scene subjects; the system packages spatial context, requests a camera plan, and turns the structured response into real Sequencer assets.

Automated pipeline

  • Collects boundaries, transforms, characters, meshes, and subject bone data from the scene.
  • Sends creative direction and structured scene context to Gemini, including optional audio input.
  • Parses generated shot plans, camera rigs, look-at targets, follow targets, and keyframes.
  • Creates CineCamera actors and writes transforms, focal length, aperture, focus distance, and camera shake into Sequencer.
  • Builds individual shots and assembles them into timed master Level Sequences.
01

Scene-aware direction

Primary and secondary characters or meshes are described with world bounds, transforms, facing information, and selected skeletal reference points.

02

Camera intelligence

Custom free, follow, and look-at rigs support weighted subjects, smooth composition damping, and 3D environment-query camera positions.

03

Editable results

The output remains native to Unreal: cameras, bindings, tracks, keyframes, sub-sequences, and a master shot timeline can all be refined by an artist.

Technical architecture

The system combines an Unreal Editor interface, C++ Blueprint libraries, a WebSocket command bridge, Python Sequencer automation, JSON scene exchange, and asynchronous Gemini requests in one production workflow.

Advanced Lighting
Sequences System

A real-time concert-lighting system for placing fixtures, authoring sequences, controlling performance properties, and previewing complete configurations.

Authoring workflow

Users can spawn different studio or concert lights, combine them with pre-placed fixtures, select the required lights, and create reusable sequences by adjusting their properties.

Sequence actions

  • Light On, Beam Light Rotate, and Random Light Moving.
  • Strobe Blink, Laser Spread, and Focus Light behaviors.
  • Beam, point, strobe, and laser light placement.
  • Save, preview, and stop controls for lighting configurations.
01

Transform controls

World/local space placement, initial rotation, vertical and horizontal orientation, and mouse-selected focus locations.

02

Beam & focus

Distance, intensity, music interaction, rotation loops, and single-point focus control.

03

Laser & strobe

Laser angle, width, beam count, spread direction and speed, plus strobe timing and intensity.

05 / 05Unreal Engine 5.7 · 2026

AI Blueprint
Generator

An Unreal Engine editor plugin that converts natural-language descriptions into real Blueprint assets and executable visual logic.

From intent to asset

A user describes the gameplay system they need. The AI expands that intent into a grounded two-phase plan, while the Unreal bridge creates the Blueprint structure first and its connected logic second.

Generated inside Unreal

  • Actor, Pawn, or Character Blueprint assets with the requested parent class.
  • Component hierarchies using Unreal's Simple Construction Script.
  • Typed variables, arrays, default values, and reflected component properties.
  • Event Graph nodes with inspected pins, configured values, and validated connections.
  • Functions with inputs, outputs, internal nodes, entry/result wiring, and pure-function support.
01

Grounded planning

Blueprint-specific prompts, Unreal node aliases, and API context constrain generation to supported engine types and graph operations.

02

Two-phase execution

Structure is created before logic so the second phase can use the actual components, variables, functions, and graph state.

03

Recoverable workflow

Each command returns structured success or error data, nodes are tracked by GUID, and the most recent generated batch can be undone.

Technical architecture

The plugin combines Gemini planning, a Python WebSocket server, reflected C++ editor APIs, JSON command execution, Kismet compilation, graph inspection, pin-level wiring, and Blueprint-native output.
