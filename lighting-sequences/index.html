01 / Overview

A lighting workspace where fixtures, motion, timing, and performance controls become reusable sequences.

Users can spawn different studio or concert lights, combine them with pre-placed fixtures, select the lights that belong to a performance, and define their behavior through a focused control interface.

The system supports quick experimentation without losing the final setup. Configurations can be previewed as a whole, stopped for adjustment, and saved for reuse.

02 / Authoring system

From fixture placement to synchronized behavior.

The toolkit brings multiple light types and performance actions into one consistent sequence-authoring workflow.

01

Place fixtures

Spawn beam, point, strobe, and laser lights or bring existing fixtures into the authored configuration.

02

Design behavior

Create actions such as Light On, Beam Light Rotate, Random Light Moving, Strobe Blink, Laser Spread, and Focus Light.

03

Preview and save

Run the complete configuration in real time, stop it for changes, and save reusable lighting sequences.

03 / Workflow

A direct path from setup to show.

Each step keeps creative iteration fast while retaining control over the individual lights.

01

Spawn

Add the fixture types required by the studio scene, concert stage, or real-time experience.

02

Select

Choose one or multiple lights and establish the group that receives the sequence behavior.

03

Configure

Adjust transforms, focus, intensity, movement, timing, spread, and music interaction.

04

Perform

Preview the sequence, stop and refine the setup, then save the finished configuration.

04 / Controls

Detailed control for every performance layer.

Shared authoring patterns make different fixture behaviors feel like parts of the same lighting system.

Placement

World and local transforms

Configure placement space, initial rotation, vertical orientation, horizontal orientation, and selected focus locations.

Beam + focus

Direct and animated light

Control distance, intensity, music interaction, rotation loops, and single-point focus behavior.

Laser

Shape the spread

Adjust laser angle, width, beam count, spread direction, and movement speed for different visual patterns.

Strobe

Time the pulse

Author blink timing and intensity while coordinating the effect with the rest of the real-time sequence.

05 / Result

One tool for
repeatable live looks.

The system turns a collection of independent Unreal lights into an authored performance layer—faster to build, easier to preview, and practical to reuse across concert, studio, and virtual-production scenes.
